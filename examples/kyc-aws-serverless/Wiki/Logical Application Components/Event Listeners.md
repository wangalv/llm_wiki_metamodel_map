# Event Listeners

Listener components that filter and normalize inbound events and prepare documents for downstream processing.

## Explanation
Event listeners filter onboarding requests, prepare documents for OCR, normalize vendor formats, and correlate transaction signals with profiles ([[2026-09-28-modernizing-kyc-aws-serverless#Event-Driven Communication Infrastructure with Amazon MSK|Event-Driven Communication Infrastructure with Amazon MSK]]).
