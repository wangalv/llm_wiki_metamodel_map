# Amazon DynamoDB

A managed NoSQL database implementing the Real-Time Decision Store for low-latency access to KYC data.

## Explanation
The Real-Time Decision Store uses Amazon DynamoDB for sub-millisecond access to KYC status, risk scores, history, and dynamic parameters ([[2026-09-28-modernizing-kyc-aws-serverless#Intelligent Knowledge Management Architecture|Intelligent Knowledge Management Architecture]]).
